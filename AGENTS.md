# Hive Showcase

This repository is the public-safe projection of ten original demonstrations.
It is not an activated RAPP Work Organization, private Hive, or federation.

- Preserve the runnable applications, acceptance criteria, and truthful limits.
- Use isolated Git worktrees and keep changes within the assigned scope.
- Use browser HTML/CSS/JavaScript, Node's built-in test runner, and Python 3.9+
  standard library. Do not introduce runtime dependencies for static hosting.
- Keep URLs repository-relative so every page works below `/hive-showcase/`.
- Keep synthetic data, assumptions, modeled outcomes, and unperformed physical,
  human, or market validation explicit.
- Never publish machine-specific paths, internal coordination prompts, provider
  conversation stores, credentials, or private execution identifiers.
- Original private execution records remain in their original checkout.
  Public redactions must be labeled as derived records, never presented as
  byte-identical originals or new executions of historical events.
- Regenerate dependent hashes and run the relevant checks after changing
  published artifacts. Do not weaken acceptance targets to make exports pass.
- Keep downloaded seed code inert and preserve source attribution and licenses.
- Publication of this reviewed showcase to its GitHub Pages repository is
  owner-authorized. Only the coordinating publisher may change remote state.
  This does not authorize purchases, outreach, native activation, or publication
  of additional private material.
- Every project retains its manifest, runnable entrypoint, documentation, tests,
  and a truthful evidence record. Human review and native authority are separate
  from passing local technical checks.
