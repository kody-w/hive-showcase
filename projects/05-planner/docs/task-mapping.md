## Deliberately changed product contract

The original intake is a simple meeting budgeter: reserve required topics,
greedily include optional topics, park the optional demonstration, reserve
wrap, and report 53 topic minutes + 2 slack + 5 wrap in 60 minutes.

The **current user-requested extension is different**:

- Every submitted commitment is mandatory; no greedy omissions.
- Exact bounded scheduling with day/task windows, fixed events and
  finish-to-start dependencies.
- Proven infeasibility, explicit unsupported/unproven states, diagnostic
  minimum-cardinality task cores when proven.
- Proven minimum repairs under the specified field-count-then-minutes
  objective, with no window, dependency, fixed-event or membership relaxation.
- Adversarial fixtures, JSON engine/export contracts, visual editable offline
  UI, and a synthetic Pocket Arcade federation preset.
- Truthful local launch/support drafts, no external activation or effects.

Consequently, the source acceptance file is preserved **as historical data**,
not falsely reported as passed. The new library input commits all six original
topics (68 minutes) plus wrap (5): **73 minutes cannot fit 60**. The original
“optional” words remain copied label text only. The new 09:00–10:30 available
window, cutoff negotiation and 2-minute template floor are explicit **new
synthetic assumptions**, not facts from the seed.

The 7-task Pocket Arcade input is original synthetic data, not copied game
code or actual tournament operations. It preserves the two breaks and fixed
check-in in every allowed repair. No project-to-project network effects occur.
